# Contributing to VEFA (v2.4.0)

We welcome contributions from fraternal brothers, sisters, and civic developers across America!

## Core Principles
1. **100% White-Label Standard**: Never commit code with hardcoded specific lodge numbers or specific towns.
2. **Senior Accessibility**: Ensure touch targets are 48px+, contrast ratios exceed WCAG AA standards, and font sizes can scale to 18px / 21px.
3. **Additive History**: Always append new features to documentation rather than replacing past history.

Please submit Pull Requests via GitHub or contact `admin@vefa.club`.
