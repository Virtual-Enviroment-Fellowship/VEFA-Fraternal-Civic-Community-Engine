# Contributing to VEFA (v2.3.1)

1. **100% White-Label Standard**: Do not hardcode specific lodge numbers (e.g. `#1706`) or specific towns in core templates.
2. **AI Harness Compliance**: Preserve tool signatures documented in [`agent.md`](agent.md) and [`openapi.json`](openapi.json).
3. **Senior Accessibility**: Ensure minimum 48px touch targets and high-contrast styling across all UI components.
